# The Game of the Kronars

Integrative project for *Paradigmas de Lenguajes* (UAM). A Haskell program finds
Dravek's optimal path on a Kronar board and writes `resultado.json`. An Elm web
page loads that file, checks it, shows the report, plays the optimal path step by
step and lets the user play their own route.

**Team:** Juan, Valentina, Jessica and Miguel.

## How to run

### 1. Haskell: generate `resultado.json`

```bash
cd haskell
runghc Kronar.hs
```

To try another board, edit `inputBoard` in the **Input** section at the top of
`Kronar.hs` and run it again. An invalid board prints the reason and creates no file.

Expected output with board t1:

```
=== The Game of the Kronars ===
Board:           [3,-2,-1,4,2]
Goal:            square 5
Optimal path:    squares [1,3,4,5]
Raw score:       8
Sapphire Rule:   -0
Ether Rule:      +10
Final score:     18
Paths evaluated: 7
File resultado.json created.
```

### 2. Haskell: run the tests

```bash
cd haskell
runghc Pruebas.hs
```

It prints the path table of each custom board and one `[PASS]` or `[FAIL]` line
per test. The expected last line is `7 of 7 optimal path tests passed.`

### 3. Elm: open the viewer

```bash
cd elm
elm make src/Main.elm --output=index.html
```

Open `elm/index.html` in a browser and press **Load resultado.json**. Choose the
file from the `haskell/` folder.

The page shows:

- the board as colored squares, with the optimal path highlighted;
- **Step-by-step playback**: Previous and Next move Dravek and announce each rule;
- **Player mode**: click the squares to build your own path and compare your
  score with the optimum;
- the report, with the scores from the JSON next to the scores recalculated in Elm.

If the file is damaged or a key is missing, the page shows an error message.
